O que é simulado e o que é real

Os dados são fictícios e as operações acontecem no navegador. Quando uma rotina reproduz uma consulta ou transação, ela mostra o SQL equivalente e diz se o comportamento foi confirmado no código ou construído como modelo didático. Nenhum simulador se conecta ao MySQL.
